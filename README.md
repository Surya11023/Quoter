# Quote Randomizer

Simple Android app that shows random quotes as notifications at random intervals.

## How to get the APK (no Android Studio needed)

1. Push this repo to GitHub (or upload the ZIP contents).
2. Go to the **Actions** tab.
3. Select **Build APK** → **Run workflow**.
4. Wait ~2-4 minutes.
5. Download the artifact **QuoteRandomizer-debug-apk**.

The APK will be signed with the debug key and can be installed directly on any Android device (min SDK 26).
